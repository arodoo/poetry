# 1.4 Objetivos

### 1.4.1 Objetivo General
Desarrollar una arquitectura para gestionar membresías y 
accesos (Poetry). Se busca un esquema desacoplado que asegure 
la calidad de datos y admita una interfaz web eficiente 
junto a un lector de huella.

### 1.4.2 Objetivos Específicos
- **Diseñar una estructura firme**: Lograr que las reglas de 
negocio estén separadas de los detalles externos mediante 
Clean Architecture.
- **Crear un núcleo escalable**: El backend en Java/Spring 
Boot debe gestionar Miembros y Zonas con eficacia.
- **Desarrollar la interfaz web**: Crear un frontend en 
React que use SDKs generados automáticamente.
- **Integrar hardware de lectura**: Validar cada ingreso 
físico mediante el uso de un lector de huella dactilar.
- **Asegurar la calidad**: Aplicar pruebas constantes, 
desde la lógica de dominio hasta el flujo completo. 
Esa es la meta.
