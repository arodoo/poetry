# 1.4 Objetivos

### 1.4.1 Objetivo General
Desarrollar una arquitectura para gestionar membresías y 
accesos (Poetry). Se usará un esquema desacoplado que asegure 
la calidad de datos y admita una interfaz web eficiente e 
integración con hardware de lectura de huella.

### 1.4.2 Objetivos Específicos
- **Diseñar una estructura de software firme**: Aplicar 
Clean Architecture y DDD para separar reglas de negocio de 
detalles externos.
- **Crear un núcleo de negocio escalable**: Desarrollar el 
backend en Java con Spring Boot para gestionar Miembros, 
Zonas y Códigos de Venta.
- **Desarrollar la interfaz web**: Crear un frontend en 
React que use SDKs generados automáticamente.
- **Integrar hardware de lectura**: Conectar el lector de 
huella dactilar para validar accesos físicos.
- **Asegurar la calidad mediante pruebas**: Aplicar testing 
desde la lógica de dominio hasta pruebas de flujo completo.
