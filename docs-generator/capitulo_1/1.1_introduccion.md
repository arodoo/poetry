# 1.1 Introducción

Este documento detalla el desarrollo de Poetry, una red para
gestionar membresías, accesos y ventas. El proyecto nace
para centralizar procesos administrativos mediante un
esquema estructurado y escalable.

Poetry sirve para aplicar estándares de ingeniería de 
software. Se utiliza Diseño Dirigido por el Dominio (DDD), 
Arquitectura Limpia y principios SOLID. La arquitectura
incluye un núcleo en Java/Spring Boot, una interfaz web en 
React y la integración de un lector de huella dactilar.

El software permite administrar usuarios y suscripciones, 
controlar zonas lógicas y dar seguimiento a ventas. El 
esquema garantiza la seguridad y el registro de cada
operación realizada en el flujo de datos.
