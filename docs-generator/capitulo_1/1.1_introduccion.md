# 1.1 Introducción

Poetry surge como una respuesta técnica ante el desorden en 
la gestión de membresías y ventas. No se trata solo de un 
software. Es una arquitectura diseñada para centralizar 
operaciones administrativas bajo un esquema que permita el 
crecimiento.

La propuesta adopta estándares modernos de ingeniería. Se 
utilizan patrones como Diseño Dirigido por el Dominio (DDD) 
y Arquitectura Limpia. Esto, unido a los principios SOLID, 
permite crear un entorno tecnológico que perdure. El núcleo 
se desarrolla en Java/Spring Boot. La interfaz web corre en 
React. Se añade un lector de huella dactilar para 
validar el ingreso físico.

Con el uso de esta propuesta, el control de usuarios y 
cuotas se vuelve directo. El registro de cada operación se 
guarda 
con rigor. Así, la seguridad de los datos queda protegida en 
todo el flujo de información.
