# 1.6 Alcances y Limitaciones

### 1.6.1 Alcances

La labor cubre desde el análisis hasta el despliegue de un
software funcional. Es el camino trazado. Los puntos clave son:

- Gestión de Membresías: registro y seguimiento de socios
  (Activo o Expirado).

- Control de Zonas: definición clara de áreas de acceso.

- Módulo de Vendedores: uso de códigos para rastrear cada
  venta realizada.

- Panel Administrativo: centro de control con datos reales
  y filtros.

- Lector de Huella: integración del hardware para validar
  entradas físicas.

- Infraestructura: pipelines de integración y estándares
  de calidad rigurosos.

### 1.6.2 Limitaciones

- Hardware Externo: solo se incluye el lector de huella.
  Otros dispositivos quedan fuera de este desarrollo.

- Escalabilidad: el despliegue es para entornos de
  desarrollo. No se busca carga masiva en la nube.

- Tiempos: el avance se acota al periodo académico.
  Lector de huella es el único hardware integrado.
