# 1.6 Alcances y Limitaciones

### 1.6.1 Alcances
La labor cubre desde el análisis hasta el despliegue de un 
software funcional. Es el camino trazado. Los puntos clave 
son:
- **Gestión de Membresías**: Registro y seguimiento de 
socios (Activo o Expirado).
- **Control de Zonas**: Definición clara de áreas de acceso.
- **Módulo de Vendedores**: Uso de códigos para rastrear 
cada venta realizada.
- **Panel Administrativo**: Centro de control con datos 
reales y filtros.
- **Lector de Huella**: Integración del hardware para 
validar entradas físicas.
- **Infraestructura**: Pipelines de integración y altos 
estándares de calidad.

### 1.6.2 Limitaciones
- **Hardware Externo**: Solo se incluye el lector de huella. 
Otros dispositivos quedan fuera de este desarrollo.
- **Escalabilidad**: El despliegue es para entornos de 
desarrollo. No se busca carga masiva en la nube.
- **Tiempos**: El avance se acota al periodo académico.
Lector de huella es el único hardware integrado. No hay 
un componente móvil.
