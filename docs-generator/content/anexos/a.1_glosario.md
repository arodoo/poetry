# A.1 Glosario de Términos

**Autenticación Biométrica:** Proceso de verificación de la identidad de un individuo mediante la medición fisiológica de características únicas, en este caso, patrones dactilares. Sustituye la necesidad de tokens físicos o contraseñas memorizadas.

**Clean Architecture (Arquitectura Limpia):** Paradigma de diseño de software propuesto por Robert C. Martin que postula la separación estricta de responsabilidades en capas concéntricas, garantizando que el núcleo de reglas de negocio permanezca agnóstico respecto a la interfaz de usuario, los frameworks o la base de datos.

**Domain-Driven Design (DDD):** Enfoque metodológico para el desarrollo de software que centra su prioridad en modelar conceptualmente el dominio del problema. Emplea un lenguaje ubicuo compartido entre expertos del negocio y desarrolladores para evitar asimetrías de información estructural.

**JSON Web Token (JWT):** Estándar abierto (RFC 7519) que define un formato compacto y autocontenido para transmitir información verificable entre partes como un objeto JSON. Se emplea preponderantemente para la autorización segura en aplicaciones web distribuidas.

**Role-Based Access Control (RBAC):** Mecanismo de seguridad informática que restringe el acceso a los subsistemas basándose en los roles asignados a los usuarios autorizados. Impide que cuentas operativas interactúen con módulos gerenciales.

**Single Page Application (SPA):** Aplicación web que interactúa con el usuario reescribiendo de forma dinámica la página actual con nuevos datos del servidor en lugar del método predeterminado de los navegadores web de cargar páginas enteras.

**Spring Boot:** Marco de trabajo del ecosistema Java diseñado para simplificar la inicialización y el desarrollo de nuevas aplicaciones empresariales, proveyendo configuraciones predeterminadas para mitigar la fatiga por configuraciones redundantes.
