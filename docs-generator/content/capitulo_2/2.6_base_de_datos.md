# 2.6 Gestión de Base de Datos

Poetry usa un esquema híbrido para el almacenamiento. En 
desarrollo, H2 permite una velocidad de iteración alta 
gracias a que corre en memoria. Para entornos reales, 
PostgreSQL ofrece la persistencia y seguridad que los datos 
de membresías exigen. Es la opción técnica estándar.

El diseño del esquema sigue las reglas de normalización. 
Se busca evitar la redundancia de datos. Tablas como 
Miembros, Zonas y Accesos están vinculadas con integridad 
referencial sólida. Esto garantiza que no existan registros 
huérfanos en ningún punto del flujo.

Las migraciones de datos se manejan con cuidado. Cada 
cambio estructural en las tablas se refleja en scripts 
técnicos. Se asegura así que la base de datos y el código Java 
estén siempre en sincronía. La salud de los datos es la 
prioridad.
