# 2.4 Tecnologías Backend

Java es el lenguaje elegido para el motor de Poetry. Su 
ecosistema técnico ofrece la robustez necesaria para 
operaciones administrativas. Spring Boot agiliza este 
proceso. Mediante la inversión de control y la inyección de 
dependencias, el desarrollo se vuelve ordenado.

Spring Data JPA gestiona el acceso a los datos. No se escriben 
consultas SQL directas si no es imperativo. Esto permite 
que la aplicación sea independiente del gestor de base de 
datos. El cambio de H2 a PostgreSQL en producción ocurre sin 
traumas técnicos. La eficiencia es alta.

Bean Validation asegura que la información sea correcta 
desde que entra al flujo. Cada petición se revisa bajo 
reglas estrictas. Así, el backend solo procesa datos que 
cumplen con el contrato definido. La seguridad técnica se 
fortalece en cada endpoint.
