# 2.7 Control de Versiones y CI/CD

El orden en el código se logra con herramientas 
automatizadas. Git es la base para el control de versiones. 
Se utilizan ramas para separar las funciones nuevas de las 
que ya están en producción. Es un flujo técnico limpio.

Husky actúa como un guardián antes de cada commit. Revisa 
que los archivos cumplan con los límites de líneas y que los 
estilos sean correctos. Esto evita que código sucio llegue al 
repositorio central. La calidad se asegura en el punto de 
origen.

Las acciones automáticas de GitHub permiten validar cada 
cambio mediante pruebas constantes. Todo el flujo, desde el 
backend hasta la generación de documentación, se monitorea. 
Se logra así un entorno de desarrollo profesional donde el 
error humano se reduce al mínimo técnico.
