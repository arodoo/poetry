# 2.6 Gestión de Base de Datos

### 2.6.1 Teoría Relacional y Normalización
El modelo relacional, propuesto inicialmente por E. F. Codd 
(1970), basa la integridad de los datos en la teoría de 
conjuntos. Poetry aplica las formas normales para eliminar 
redundancias. Cada dato existe en un solo lugar. Esto 
evita anomalías de actualización donde cambiar un nombre 
en un registro no lo actualiza en otros.

### 2.6.2 Propiedades ACID
Para garantizar transacciones fiables, el motor de base de 
datos debe cumplir con ACID:
- **Atomicidad**: O todo se guarda, o nada.
- **Consistencia**: La base de datos pasa de un estado válido 
a otro válido.
- **Aislamiento**: Las transacciones concurrentes no 
interfieren entre sí.
- **Durabilidad**: Una vez confirmado, el dato persiste ante 
fallos de energía.
Estas garantías son no negociables para la integridad de las 
membresías.
