# 2.7 Ingeniería de Software y DevOps

### 2.7.1 Integración Continua (CI)
Martin Fowler (2006) define la Integración Continua como la 
práctica de integrar el trabajo frecuentemente. No es solo 
automatización. Es una disciplina para reducir el "Infierno 
de Integración". Poetry utiliza GitHub Actions para compilar 
y probar cada cambio. Si una prueba falla, el equipo es 
alertado de inmediato. La calidad se construye, no se 
inspecciona al final.

### 2.7.2 Control de Versiones Distribuido
Git permite que cada desarrollador tenga una copia completa 
del historial del proyecto. Esto no solo es una copia de 
seguridad, sino un mecanismo para permitir el trabajo en 
paralelo. Las ramas de características (feature branches) 
permiten experimentar sin riesgo para la línea principal de 
desarrollo.
