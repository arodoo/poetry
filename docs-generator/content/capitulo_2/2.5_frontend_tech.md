# 2.5 Tecnologías Frontend

### 2.5.1 Paradigma Declarativo
El desarrollo de interfaces ha evolucionado del imperativo 
(manipular el DOM directamente) al declarativo. Con React, 
Poetry describe *cómo debe lucir* la interfaz para un estado 
dado. La librería se encarga de los pasos intermedios. Esto 
reduce errores de sincronización visual.

### 2.5.2 Virtual DOM y Reconciliación
React mantiene una copia ligera del árbol de elementos en 
memoria: el Virtual DOM. Cuando cambia un dato, crea un 
nuevo árbol virtual y lo compara con el anterior. Este 
proceso de diferenciación (diffing) calcula la menor 
cantidad de operaciones necesarias para actualizar el DOM 
real. Esta optimización matemática es lo que da fluidez al 
dashboard administrativo.
