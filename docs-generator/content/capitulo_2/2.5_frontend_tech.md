# 2.5 Tecnologías Frontend

### 2.5.1 Modelo Declarativo
El desarrollo de interfaces ha evolucionado del imperativo 
(manipular el DOM directamente) al declarativo. Con React, 
Poetry describe *cómo debe lucir* la interfaz para un estado 
dado. La librería se encarga de los pasos intermedios. Esto 
reduce errores de sincronización visual.

### 2.5.2 Tailwind CSS y Utilidad como Filosofía
Tailwind CSS adopta un enfoque utility-first para los estilos.
En lugar de escribir clases semánticas en hojas separadas,
se aplican clases atómicas directamente en el marcado JSX.
Esto reduce la distancia entre la estructura y la apariencia,
acelerando la iteración visual sin sacrificar consistencia.

### 2.5.3 Virtual DOM y Reconciliación
React mantiene una copia ligera del árbol de elementos en 
memoria: el Virtual DOM. Hunt (2013) describe esto como 
un replanteamiento de las mejores prácticas tradicionales. 
Cuando cambia un dato, crea un nuevo árbol virtual y lo 
compara con el anterior. Este proceso de diferenciación 
(diffing) calcula la menor cantidad de operaciones 
necesarias para actualizar el DOM real.
