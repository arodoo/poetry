# 2.2 Arquitectura Limpia (Clean Architecture)

La independencia técnica es el norte de Poetry. Clean 
Architecture permite lograrlo. Mediante un esquema de capas 
concéntricas, se asegura que el núcleo de la aplicación no 
conozca los detalles externos. La base de datos o la web son 
solo accesorios. Son infraestructuras que pueden mutar sin 
afectar el corazón del negocio.

La regla de dependencia es estricta. El código solo puede 
apuntar hacia adentro. Esta protección técnica blinda los 
Casos de Uso ante cambios en librerías de terceros. Es una 
barrera necesaria. El software se vuelve así fácil de 
probar y de mantener en el tiempo.

Al separar los adaptadores de la lógica pura, se logra un 
desacoplamiento real. Esto permite que el lector de huella 
dactilar se integre como un componente más. Si el hardware 
cambia mañara, la lógica de acceso permanece intacta. Esa es 
la fuerza de este diseño.
