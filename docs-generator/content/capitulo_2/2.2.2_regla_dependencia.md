### 2.2.2 La Regla de Dependencia

El diagrama de Arquitectura Limpia se representa como una 
serie de círculos concéntricos. La regla de oro que gobierna 
este movimiento es simple: las dependencias de código fuente 
solo pueden apuntar hacia adentro.

Nada en un círculo interno puede saber nada de un círculo 
externo. El nombre de una tabla de base de datos, definido 
en la capa de Infraestructura (externa), no puede aparecer 
jamás en la capa de Casos de Uso (interna).

Esto invierte el flujo de control tradicional. En arquitecturas
antiguas, la lógica de negocio llamaba directamente a la base
de datos. Aquí, mediante interfaces y polimorfismo, la base 
de datos "sirve" al negocio sin que este conozca su 
existencia. Es una técnica de protección técnica 
invaluable para mantener la integridad del núcleo.
