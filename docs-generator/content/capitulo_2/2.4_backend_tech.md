# 2.4 Tecnologías Backend

### 2.4.1 Ecosistema Java y la JVM
Java se seleccionó por su estabilidad y su modelo de gestión 
de memoria definido en su especificación de lenguaje 
(Gosling et al., 2014). La Máquina Virtual de Java (JVM) 
abstrae la complejidad del hardware subyacente. El Garbage 
Collector ejecuta algoritmos de limpieza generacional que 
previenen fugas de memoria, clave para esquemas de control 
de acceso que operan de forma ininterrumpida.

### 2.4.2 Spring Boot e Inversión de Control
Spring Boot no es solo un servidor web. Su núcleo es el 
contenedor de Inversión de Control (IoC). Este patrón quita 
la responsabilidad de crear objetos a las clases del negocio 
y se la entrega al framework. Esto facilita las pruebas 
unitarias, ya que permite inyectar simulacros (mocks) en 
lugar de dependencias reales con total transparencia.
