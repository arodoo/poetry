# 2.5 Tecnologías Frontend

React lidera la interfaz de usuario. No es solo una librería 
de vistas. Es un esquema basado en componentes que permite 
reutilizar la lógica visual. Vite actúa como el motor de 
construcción. Ofrece una velocidad de despliegue superior a 
otros entornos antiguos.

El diseño evita librerías de estilos pesadas. Se usa CSS 
Vanilla para tener un control total sobre la estética del 
software. Esto garantiza una carga rápida y una identidad 
visual propia. La experiencia de usuario se vuelve fluida y 
directa.

La sincronización con el backend ocurre mediante SDKs 
generados. No se usa fetch o axios de forma manual. Esto 
evita errores de tipado y asegura que el frontend use 
siempre la última versión del contrato del API. El desarrollo 
se vuelve así un proceso seguro y firme.
