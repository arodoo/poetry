# 1.6 Alcances y Limitaciones

### 1.6.1 Alcances del Proyecto
El aplicativo Poetry abarca la totalidad del ciclo de vida 
administrativo de un miembro:
- Registro de datos personales y huella dactilar.
- Gestión de suscripciones y pagos (historial).
- Dashboard administrativo para visualización de estados.
- API REST documentada para integración futura.

El hardware soportado se limita estrictamente a lectores de 
huella dactilar compatibles con el SDK de DigitalPersona o 
similares que expongan una interfaz estándar en Windows.

### 1.6.2 Limitaciones Técnicas
Para mantener la viabilidad del desarrollo dentro de los 
tiempos académicos, se establecen límites claros:
- **No Móvil**: No se desarrollará una aplicación nativa para 
iOS o Android. Toda la interacción es vía web responsiva.
- **Hardware de Torniquetes**: El software emite la señal de 
"Acceso Autorizado", pero la integración electrónica física 
con relevadores o torniquetes específicos queda fuera del 
alcance.
- **Medios de Pago Online**: La plataforma registra pagos, pero 
no procesa transacciones bancarias en tiempo real ni almacena 
datos de tarjetas de crédito.
