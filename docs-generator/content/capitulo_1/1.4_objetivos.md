# 1.4 Objetivos

### 1.4.1 Objetivo General

Desarrollar e implementar una plataforma de gestión de 
accesos y membresías ("Poetry") basada en arquitectura de 
microservicios lógicos y biometría dactilar, que garantice 
la unicidad de la identidad del usuario y optimice los 
tiempos de validación en centros de alto tráfico.

### 1.4.2 Objetivos Específicos

- **Diseñar** un núcleo de dominio desacoplado utilizando 
Domain-Driven Design para aislar las reglas de negocio de 
la infraestructura tecnológica.
- **Construir** una interfaz de usuario reactiva que reduzca 
a menos de tres clics las operaciones de consulta y alta de 
socios.
- **Integrar** un motor de lectura de huella dactilar que 
se comunique directamente con el backend mediante adaptadores 
seguros.
- **Asegurar** la integridad de los datos mediante un esquema 
de base de datos normalizado y validaciones estrictas en la 
capa de aplicación.
- **Implementar** un pipeline de CI/CD que garantice la 
calidad del código mediante análisis estático y pruebas 
automáticas antes de cada despliegue.
