# 4.4 Conclusiones y Recomendaciones

### 4.4.1 Conclusiones
1. **Viabilidad de Clean Architecture**: Se demostró que es 
posible aplicar arquitecturas rigurosas en proyectos de 
mediana escala sin incurrir en "over-engineering", siempre 
que se respete el principio de separación de capas.
2. **Impacto de la Biometría**: La inclusión de hardware 
biométrico transformó el modelo operativo, pasando de una 
seguridad basada en confianza a una basada en certeza 
matemática.
3. **Escalabilidad**: El diseño stateless del backend permite 
un crecimiento sostenido sin reescritura de código base.

### 4.4.2 Trabajos Futuros
Para futuras iteraciones o tesis de posgrado, se sugiere:
- **Microservicios**: Si la base de usuarios supera los 100k, 
desacoplar el módulo de `AccessControl` en un servicio 
independiente.
- **Biometría Facial**: Investigar la viabilidad de reconocimiento 
facial pasivo para eliminar la fricción de tocar un sensor.
- **Federación**: Implementar OAuth2 para permitir login con 
proveedores externos.
