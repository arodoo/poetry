# 3.1 Especificación de Requerimientos

### 3.1.1 Requerimientos Funcionales

El núcleo funcional de Poetry se adhiere a las necesidades 
críticas de operación en tiempo real. Se han identificado 
tres épicas principales que gobiernan el alcance del 
desarrollo:

**1. Gestión de Identidad Biométrica**
- *Historia de Usuario 01*: Como administrador, deseo capturar 
la huella dactilar de un socio para vincularla irrevocablemente 
a su cuenta, evitando suplantaciones.
- *Criterio de Aceptación*: El sistema debe rechazar huellas 
duplicadas con un mensaje de error explícito y almacenar el 
template biométrico en formato binario seguro.

**2. Control de Acceso en Tiempo Real**
- *Historia de Usuario 02*: Como sistema, debo validar el 
estado de una membresía en menos de 200 milisegundos tras 
la lectura de la huella.
- *Criterio de Aceptación*: Respuesta visual inmediata (Verde/Rojo) 
y registro inmutable del evento de acceso con timestamp.

**3. Administración Financiera**
- *Historia de Usuario 03*: Como gerente, requiero visualizar 
un reporte de ingresos por periodo para tomar decisiones de 
flujo de caja.
- *Criterio de Aceptación*: Generación de gráficos de 
tendencia y exportación de datos a formatos estándar.
