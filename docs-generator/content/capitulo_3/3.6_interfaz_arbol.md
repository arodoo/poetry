# 3.6 Artefactos de Interfaz y Catálogo de Componentes

Nielsen (1993) establece que la consistencia visual
reduce la carga cognitiva del usuario. Poetry
codifica esta consistencia en un catálogo formal
(`ui-component-catalog.md`) que dicta los tokens
de diseño: paleta de colores, tipografía, espaciado
y comportamiento de cada componente reutilizable.

La interfaz se construye sobre React con Hooks
para el ciclo de vida. Context API combinada con
React Query gestiona el estado del servidor (caché,
reintentos, invalidación), asegurando datos frescos
sin saturar la red.

Se implementan patrones de «Optimistic UI» donde
la vista asume el éxito inmediato y revierte ante
error, eliminando la percepción de latencia.
