# 3.3 Diseño de la Base de Datos

### 3.3.1 Modelo Entidad-Relación

La persistencia se gestiona mediante un esquema relacional 
normalizado en PostgreSQL. Las tablas principales reflejan 
los Agregados del dominio:

- **`members`**: Tabla maestra con datos demográficos. Su 
clave primaria es un UUID para facilitar la portabilidad 
entre instancias distribuidas.
- **`biometric_templates`**: Relación 1:1 con `members`. 
Almacena el blob binario de la huella. Se separa para no 
cargar datos pesados en consultas administrativas simples.
- **`subscriptions`**: Relación 1:N. Historial de pagos y 
vigencias. Permite auditoría financiera completa.
- **`access_logs`**: Tabla inmutable que registra cada intento 
de entrada. Indexada por fecha para reportes rápidos.

Las claves foráneas aseguran la integridad referencial, 
impidiendo, por ejemplo, tener un pago huérfano sin socio 
asignado.
