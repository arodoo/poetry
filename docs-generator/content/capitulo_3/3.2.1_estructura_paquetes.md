# 3.2 Arquitectura del Sistema

### 3.2.1 Estructura de Paquetes y Capas

La implementación en Java sigue una correspondencia estricta 
con los círculos concéntricos de la Arquitectura Limpia. El 
árbol de paquetes refleja las fronteras arquitectónicas:

- **`com.poetry.domain`**: Es el núcleo agnóstico. Contiene 
las entidades (`Member`, `AccessLog`) y los puertos 
(interfaces) que definen qué necesita el negocio, pero no 
cómo se cumple. No tiene dependencias de frameworks externos.

- **`com.poetry.application`**: Orquesta el flujo de datos. 
Aquí residen los Casos de Uso (`RegisterMemberUseCase`) que 
implementan la lógica específica de la aplicación. Utiliza 
DTOs para comunicarse con el mundo exterior, protegiendo las 
entidades de dominio.

- **`com.poetry.infrastructure`**: Contiene los detalles 
técnicos. Aquí se implementan los repositorios JPA, los 
controladores REST de Spring Boot y los adaptadores para el 
lector de huellas. Es la única capa que "conoce" a SQL o a 
HTTP.
