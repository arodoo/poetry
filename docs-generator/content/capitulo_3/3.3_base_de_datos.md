# 3.3 Diseño de la Base de Datos

El orden de la información es un factor clave en Poetry. Se diseñó un 
esquema relacional sólido para evitar la pérdida de datos.

La tabla de ingresos vincula cada intento de entrada con un 
socio específico. Se registra la fecha, la hora y la zona 
intentada. Así, el historial operativo es completo. Las 
relaciones entre Miembros y Suscripciones aseguran que un 
usuario solo acceda si tiene un pago activo.

El uso de llaves foráneas y restricciones de integridad 
mecaniza la salud del esquema. No hay espacio para datos 
inconsistentes. La base de datos actúa como el último filtro 
de seguridad técnica ante cualquier error en las capas 
superiores. Todo es coherente.
