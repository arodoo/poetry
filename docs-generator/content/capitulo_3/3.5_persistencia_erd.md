# 3.5 Artefactos de Persistencia y Modelado de Datos

La persistencia se gestiona con un esquema
relacional normalizado en PostgreSQL. Date (2003)
prescribe que la Tercera Forma Normal (3NF) elimina
dependencias transitivas entre atributos no clave.

Las tablas principales reflejan los Agregados del
dominio: `members` almacena datos demográficos con
UUID como clave primaria; `biometric_templates`
mantiene el blob binario separado para no penalizar
consultas administrativas; `subscriptions` guarda
el historial de pagos; y `access_logs` registra
cada intento de entrada como registro inmutable.

Índices compuestos sobre `(member_id, status,
end_date)` permiten verificar el estado activo
sin leer la tabla completa (Index Only Scan). Los
logs se particionan por rangos de fecha para
mantener ligero el conjunto de datos operativos.
