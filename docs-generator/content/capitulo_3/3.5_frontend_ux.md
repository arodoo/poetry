# 3.5 Desarrollo del Frontend y UX

La interfaz de Poetry busca la eficiencia administrativa. Se 
desarrolló con React para lograr una respuesta visual 
rápida. El dashboard central muestra el estado de los 
socios de forma directa.

La experiencia de usuario se diseñó para reducir la fatiga en 
puestos de control. Colores claros y navegación intuitiva 
guían al encargado. El uso de componentes reutilizables 
asegura que toda la aplicación tenga una identidad visual 
firme.

El proceso de registro de huellas dactilares es el punto 
más crítico. Se implementó un flujo visual que indica cada 
paso al usuario. Así, la captura del dato biométrico ocurre 
sin errores técnicos. Se logra integrar tecnología compleja 
en un entorno sencillo de operar.
