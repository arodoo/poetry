# 3.5 Arquitectura Frontend y UX

### 3.5.1 Gestión de Estado y Reactividad
La interfaz de usuario se construye sobre React, utilizando 
Hooks para el ciclo de vida de los componentes. Para evitar 
el "prop drilling" (pasar datos por múltiples niveles), se 
emplea `Context API` combinada con `React Query`. Esta última 
librería maneja el estado del servidor (caché, reintentos, 
invalidación), asegurando que el dashboard siempre muestre 
datos frescos sin saturar la red.

### 3.5.2 Optimización de la Experiencia (UX)
Se implementan patrones de "Optimistic UI". Cuando un usuario 
realiza una acción (ej. renovar membresía), la interfaz 
asume el éxito inmediato y actualiza la vista antes de recibir 
la confirmación del servidor. Si llegase a ocurrir un error, 
se revierte el cambio y se notifica. Esta técnica elimina la 
percepción de latencia, creando una sensación de inmediatez 
crucial para la operación fluida en recepción.
