# 3.4 Integración de API

La comunicación entre el backend y el frontend es técnica y 
estricta. Se utiliza OpenAPI v3 para definir los contratos. 
Esto permite que ambas partes hablen el mismo idioma sin 
ambigüedades.

Cada endpoint está documentado. El proceso de validación de 
acceso por huella dactilar ocurre mediante peticiones 
REST seguras. Los códigos de respuesta HTTP indican con 
precisión si la operación fue exitosa o si hubo un fallo de 
permisos.

La generación automática de SDKs blinda la integración. El 
frontend no adivina las rutas ni los tipos de datos. Los 
usa tal como el backend los define. Este flujo técnico 
elimina los desajustes entre capas. La sincronía es total.
