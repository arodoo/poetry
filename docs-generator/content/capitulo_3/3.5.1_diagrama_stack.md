### 3.5.1 Visualización del Stack Tecnológico

El siguiente diagrama muestra las cinco capas del sistema,
desde el hardware hasta la interfaz de usuario. Cada capa
expone únicamente lo que la capa superior necesita, sin
revelar detalles de implementación. Esta opacidad entre
capas es el principio que hace al sistema resistente al
cambio de proveedores.

*Nota técnica: Esta figura fue generada programáticamente
con Python y la librería matplotlib, garantizando que
cualquier cambio de stack se refleje en la documentación
con un simple re-run del script.*
