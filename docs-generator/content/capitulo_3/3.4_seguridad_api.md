# 3.4 Seguridad e Integración de API

### 3.4.1 Autenticación y Autorización
La seguridad se implementa mediante "Stateless Authentication" 
con JSON Web Tokens (JWT). Al iniciar sesión, el servidor 
firma un token que contiene los roles del usuario (RBAC). 
El backend valida la firma criptográfica en cada petición, 
eliminando la necedidad de almacenar sesiones en memoria. 
Esto permite que el API sea completamente RESTful.

### 3.4.2 Contratos de Interfaz (OpenAPI)
Para evitar la deriva entre el frontend y el backend, Poetry 
utiliza un enfoque "Contract First". Se define la especificación 
en OpenAPI v3 (YAML). A partir de este contrato, se genera 
automáticamente el código cliente (SDK) en TypeScript. Esto 
garantiza que si la API cambia, el error se detecta en tiempo 
de compilación en el frontend, no en tiempo de ejecución.
